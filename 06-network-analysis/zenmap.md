# Zenmap

## Overview

Zenmap is the graphical user interface for Nmap and can be used for network discovery and security auditing.

This tool was covered as part of my Cyber Threat Monitoring Level I training under Network Analysis.

## Objectives

- Understand basic network discovery
- Identify hosts and available network services
- Familiarize myself with Nmap scanning concepts
- Understand how network scanning can support security assessment

## Skills & Knowledge

- Network discovery
- Basic port scanning concepts
- Host identification
- Service identification
- Network security assessment fundamentals

## Cybersecurity Relevance

Network discovery and scanning can help security professionals understand the systems and services present within an authorized network.

This information can support vulnerability assessment, network inventory, troubleshooting, and security monitoring.

> Scanning should only be performed on systems and networks where proper authorization has been provided.
