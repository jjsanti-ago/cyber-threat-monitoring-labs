# Wireshark

## Overview

Wireshark is a network protocol analyzer used to capture and inspect network traffic.

This tool was covered as part of my Cyber Threat Monitoring Level I training under Network Analysis.

## Objectives

- Understand basic network traffic analysis
- Capture and inspect network packets
- Identify common network protocols
- Familiarize myself with packet-level information
- Develop foundational network troubleshooting and analysis skills

## Skills & Knowledge

- Packet capture
- Network traffic analysis
- Protocol identification
- Basic packet inspection
- Network troubleshooting

## Cybersecurity Relevance

Network traffic analysis can help security analysts identify unusual communication patterns, investigate suspicious connections, and understand network activity during security investigations.

Packet analysis can provide additional context when investigating potential security incidents.
