# Splunk

## Overview

Splunk is a platform used to collect, search, analyze, and visualize machine-generated data such as logs and events.

Splunk was introduced as part of my Cyber Threat Monitoring Level I training under Security Monitoring and Vulnerability Assessment.

## Objectives

- Understand the purpose of security information and event analysis
- Familiarize myself with log and event data
- Learn basic concepts of searching and analyzing security-related information
- Understand how centralized log analysis can support security monitoring

## Skills & Knowledge

- Log analysis fundamentals
- Event monitoring
- Security data investigation
- Search and filtering concepts
- Basic SIEM concepts

## Cybersecurity Relevance

Centralized log analysis is an important part of Security Operations Center (SOC) activities.

Security analysts can use security logs and events to identify unusual activity, investigate alerts, correlate information, and support incident investigations.

## Training Exposure

My training included installing and becoming familiar with Splunk as part of the security monitoring and vulnerability assessment activities.

This provided foundational exposure to security monitoring concepts and the use of centralized security data for analysis.
