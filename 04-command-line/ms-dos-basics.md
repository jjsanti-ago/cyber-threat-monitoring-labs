# MS-DOS / Command Prompt Basics

## Overview

This laboratory activity covered basic command-line operations using the Windows Command Prompt as part of my Cyber Threat Monitoring Level I training.

## Objectives

- Understand basic command-line navigation
- Execute common Windows commands
- Gather basic system and network information
- Develop familiarity with command-line troubleshooting

## Command-Line Commands Covered

### File and Directory Management

- `CD` / `CHDIR` — Change the current directory
- `DIR` — Display files and directories
- `MD` / `MKDIR` — Create directories
- `RD` / `RMDIR` — Remove directories
- `COPY` — Copy files
- `XCOPY` — Copy files and directory structures
- `ROBOCOPY` — Copy files and directories
- `MOVE` — Move files or directories
- `DEL` / `ERASE` — Delete files
- `REN` / `RENAME` — Rename files or directories
- `ATTRIB` — View or modify file attributes
- `REPLACE` — Replace files

### System Information and Administration

- `SYSTEMINFO` — Display detailed system information
- `DRIVERQUERY` — Display installed device drivers
- `TASKLIST` — Display running processes
- `TASKKILL` — Terminate processes
- `SC` — Manage Windows services
- `SCHTASKS` — Manage scheduled tasks
- `GPRESULT` — Display applied Group Policy information
- `OPENFILES` — Display open files
- `SHUTDOWN` — Shut down or restart Windows

### Network and Troubleshooting

- `IPCONFIG` — Display network configuration
- `PING` — Test basic network connectivity
- `PATH` — Display or modify the command search path
- `HOSTNAME` — Display the computer name

### Disk and File System

- `CHKDSK` — Check a disk for file-system errors
- `CHKNTFS` — Manage NTFS volume checking
- `DISKPART` — Manage disks, partitions, and volumes
- `FORMAT` — Format a disk
- `CONVERT` — Convert file systems
- `FSUTIL` — Manage file-system functions
- `RECOVER` — Recover readable information from a damaged disk
- `VOL` — Display volume information
- `LABEL` — Manage volume labels
- `COMPACT` — Manage NTFS compression
- `SUBST` — Associate a path with a drive letter

### Text and Data Processing

- `FIND` — Search for text in files
- `FINDSTR` — Search for text patterns
- `SORT` — Sort command output
- `MORE` — Display output one screen at a time
- `FC` — Compare files
- `COMP` — Compare file contents
- `ECHO` — Display messages or command output

### Batch and Command Processing

- `CALL` — Call another batch script
- `FOR` — Perform commands for items in a set
- `GOTO` — Direct execution to a label
- `IF` — Perform conditional processing
- `PAUSE` — Pause command execution
- `REM` — Add comments to batch scripts
- `EXIT` — Exit Command Prompt or a script
- `SET` — Display or modify environment variables
- `SETLOCAL` — Begin localization of environment changes
- `ENDLOCAL` — End localization of environment changes
- `SHIFT` — Shift batch parameters
- `START` — Start a program or command
- `DOSKEY` — Edit command lines and create macros

### Windows Configuration and Security

- `CACLS` — Display or modify access control lists for files and directories
- `ICACLS` — Display or modify file and folder permissions
- `BCDEDIT` — Manage Windows boot configuration data
- `REG` — Manage the Windows Registry from the command line
- `SC` — Query or configure Windows services
- `SCHTASKS` — Manage scheduled tasks

### Other Commands Covered

- `ASSOC` — Display or modify file extension associations
- `BREAK` — Enable or disable extended CTRL+C checking
- `CHCP` — Display or change the active code page
- `CLS` — Clear the Command Prompt screen
- `CMD` — Start a new Command Prompt instance
- `COLOR` — Change Command Prompt colors
- `COMPACT` — Display or modify NTFS file compression
- `DATE` — Display or set the system date
- `FTYPE` — Display or modify file types used with file extension associations
- `GRAFTABL` — Enable Windows to display an extended character set
- `HELP` — Display help information for Windows commands
- `MODE` — Configure system devices and ports
- `MORE` — Display output one screen at a time
- `PATH` — Display or modify the command search path
- `POPD` — Restore the previous directory saved by `PUSHD`
- `PRINT` — Print a text file
- `PROMPT` — Customize the Command Prompt
- `PUSHD` — Save the current directory and change to another directory
- `SET` — Display or modify environment variables
- `TIME` — Display or set the system time
- `VER` — Display the Windows version
- `VERIFY` — Configure verification of file writes
- `VOL` — Display volume information
- `WMIC` — Command-line interface for Windows Management Instrumentation
Used to display detailed information about the Windows system.

## Skills & Knowledge

- Command-line navigation
- Basic network troubleshooting
- System information gathering
- Windows command-line operations
- Basic network configuration awareness

## Cybersecurity Relevance

Command-line tools are useful for system troubleshooting, network diagnostics, information gathering, and security investigations.

Understanding basic command-line operations provides a foundation for working with Windows systems and analyzing system or network-related issues.
