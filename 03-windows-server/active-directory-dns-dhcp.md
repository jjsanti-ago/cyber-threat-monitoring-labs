# Windows Server: Active Directory, DNS & DHCP

## Overview

This laboratory activity covered basic Windows Server configuration involving Active Directory Domain Services (AD DS), Domain Name System (DNS), and Dynamic Host Configuration Protocol (DHCP) as part of my Cyber Threat Monitoring Level I training.

## Objectives

- Understand the purpose of Windows Server roles and services
- Configure a basic Active Directory environment
- Understand the role of DNS in a Windows network
- Understand the role of DHCP in IP address assignment
- Familiarize myself with basic server and network administration concepts

## Active Directory Domain Services (AD DS)

AD DS provides centralized management of users, computers, groups, and other resources within a Windows domain environment.

### Learning Exposure

- Basic Active Directory environment setup
- Understanding users and computer accounts
- Domain-based administration concepts
- Centralized resource management

## Domain Name System (DNS)

DNS translates domain names into IP addresses and helps devices locate services and resources within a network.

### Learning Exposure

- Understanding DNS concepts
- Basic DNS configuration
- Name resolution within a Windows environment

## Dynamic Host Configuration Protocol (DHCP)

DHCP automatically provides network configuration information such as IP addresses to client devices.

### Learning Exposure

- Understanding DHCP operation
- IP address assignment
- Basic network configuration concepts

## Cybersecurity Relevance

AD DS, DNS, and DHCP are common components of enterprise networks.

Understanding these services provides foundational knowledge for troubleshooting, network monitoring, access management, and security investigations.

Security events involving user accounts, authentication, DNS activity, or network configuration can also be relevant during cybersecurity monitoring and incident investigation.
