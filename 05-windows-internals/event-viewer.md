# Windows Event Viewer

## Overview

Windows Event Viewer is a Windows administrative utility used to view and analyze system, security, application, and other event logs.

This tool was covered as part of my Cyber Threat Monitoring Level I training under Windows Internals.

## Objectives

- Understand the purpose of Windows event logs
- Navigate Event Viewer
- Identify different event log categories
- Review recorded system and security events
- Understand how logs can support troubleshooting and investigation

## Skills & Knowledge

- Event log navigation
- Log analysis
- Event identification
- Basic Windows security monitoring
- Troubleshooting through system logs

## Cybersecurity Relevance

Windows event logs can provide valuable information during security monitoring and incident investigation.

Security analysts can review events related to authentication, account activity, system changes, applications, and other activities to identify unusual or potentially suspicious behavior.

Event logs can also help establish a timeline when investigating an incident.
