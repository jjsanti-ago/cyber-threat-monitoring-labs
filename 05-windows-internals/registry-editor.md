# Registry Editor

## Overview

Registry Editor is a Windows utility used to view and manage configuration information stored in the Windows Registry.

This tool was covered as part of my Cyber Threat Monitoring Level I training under Windows Internals.

## Objectives

- Understand the purpose of the Windows Registry
- Navigate Registry keys and values
- Familiarize myself with Windows configuration data
- Understand how system and application settings can be stored in the Registry

## Skills & Knowledge

- Registry navigation
- Registry keys and values
- Windows configuration analysis
- Basic system administration

## Cybersecurity Relevance

The Windows Registry can contain configuration information relevant to system administration and security investigations.

Security analysts may examine Registry artifacts when investigating system changes, persistence mechanisms, software activity, or other suspicious behavior.

Registry modifications should be handled carefully because incorrect changes can affect system functionality.
