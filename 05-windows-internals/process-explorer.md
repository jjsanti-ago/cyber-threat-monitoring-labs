# Process Explorer

## Overview

Process Explorer is a Windows system monitoring utility used to examine running processes and their relationships.

This tool was covered as part of my Cyber Threat Monitoring Level I training under Windows Internals.

## Objectives

- Understand how Windows processes are organized
- Examine running processes
- Identify parent and child process relationships
- Familiarize myself with process properties and system activity

## Skills & Knowledge

- Process identification
- Process hierarchy analysis
- System activity monitoring
- Windows process management

## Cybersecurity Relevance

Process analysis can help security analysts investigate unusual or potentially suspicious activity on a Windows endpoint.

Examining process relationships and system activity can provide useful information during endpoint investigation and threat analysis.
