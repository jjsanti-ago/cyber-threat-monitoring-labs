# Process Monitor

## Overview

Process Monitor is a Windows monitoring utility that provides detailed information about system activity, including process, file system, registry, and network-related activity.

This tool was covered as part of my Cyber Threat Monitoring Level I training under Windows Internals.

## Objectives

- Understand real-time Windows system activity
- Monitor process and system events
- Observe file system activity
- Observe Registry activity
- Familiarize myself with event filtering and analysis

## Skills & Knowledge

- Process activity monitoring
- File system activity analysis
- Registry activity monitoring
- Event filtering
- Basic system behavior analysis

## Cybersecurity Relevance

Process Monitor can help analysts investigate suspicious behavior by examining activities generated by processes.

Monitoring file system and Registry activity can provide useful context when investigating potentially unwanted or malicious behavior on a Windows endpoint.
