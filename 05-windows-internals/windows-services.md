# Windows Services

## Overview

Windows Services is a Windows management interface used to view and manage background services running on a Windows system.

This tool was covered as part of my Cyber Threat Monitoring Level I training under Windows Internals.

## Objectives

- Understand the purpose of Windows services
- Identify services running on a Windows system
- Review service status and configuration
- Familiarize myself with basic service management

## Skills & Knowledge

- Windows service identification
- Service status monitoring
- Basic service management
- Windows system administration
- System troubleshooting

## Cybersecurity Relevance

Windows services operate in the background and can perform important system and application functions.

Reviewing services can support endpoint investigation by helping analysts identify unfamiliar, unexpected, or potentially suspicious services.

Understanding normal system services can also help establish a baseline when investigating abnormal system behavior.
