# URLScan

## Overview

URLScan is a web-based service used to analyze and inspect websites and URLs by observing their behavior and associated network activity.

This tool was covered as part of my Cyber Threat Monitoring Level I training under Threat Intelligence.

## Objectives

- Understand the purpose of URL analysis
- Learn how URLs and websites can be investigated
- Review information associated with web activity
- Familiarize myself with basic web-based threat intelligence

## Skills & Knowledge

- URL analysis
- Web-based threat intelligence
- Indicator investigation
- Domain and website analysis
- Security information gathering

## Cybersecurity Relevance

URL analysis can provide useful context when investigating potentially suspicious websites, phishing attempts, malicious links, or other web-based threats.

Security analysts can use available information about a URL and its associated activity to support investigation and threat assessment.

## Responsible Use

URL analysis should be performed responsibly. Sensitive or private URLs should not be submitted to public analysis services without proper authorization.
