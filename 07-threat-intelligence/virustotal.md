# VirusTotal

## Overview

VirusTotal is an online service that can be used to analyze files, URLs, domains, and other indicators using multiple security engines and threat intelligence sources.

This tool was covered as part of my Cyber Threat Monitoring Level I training under Threat Intelligence.

## Objectives

- Understand the purpose of VirusTotal
- Learn how security indicators can be analyzed
- Review malware detection results
- Understand the importance of multiple security engines
- Familiarize myself with basic threat intelligence analysis

## Skills & Knowledge

- Threat intelligence gathering
- Indicator analysis
- Malware detection result interpretation
- URL and file reputation checking
- Security research

## Cybersecurity Relevance

Threat intelligence platforms can help analysts gather information about potentially suspicious files, URLs, domains, and other indicators.

VirusTotal can provide additional context during an investigation by aggregating detection results and other available information from multiple sources.

## Responsible Use

VirusTotal should be used responsibly when analyzing security indicators.

Sensitive, confidential, or personally identifiable information should not be uploaded without proper authorization.
