# TOR Browser

## Overview

TOR Browser is a privacy-focused web browser that uses the Tor network to route internet traffic through multiple relays.

This tool was covered as part of my Cyber Threat Monitoring Level I training under Threat Intelligence.

## Objectives

- Understand the basic concept of the Tor network
- Learn how traffic can be routed through multiple relays
- Understand privacy and anonymity concepts
- Recognize security considerations associated with anonymous network activity

## Skills & Knowledge

- Privacy and anonymity concepts
- Tor network fundamentals
- Security awareness
- Basic network privacy concepts
- Threat intelligence awareness

## Cybersecurity Relevance

Understanding privacy technologies and anonymous network activity is relevant to cybersecurity because legitimate users and threat actors may both use privacy-enhancing technologies.

Security professionals should understand how anonymization can affect network visibility and investigation.

## Security Considerations

Tor can provide legitimate privacy benefits, but anonymous network activity can also present challenges for security monitoring and investigation.

Security teams may consider network context, endpoint telemetry, and other indicators when investigating suspicious activity associated with anonymized connections.

## Responsible Use

Tor Browser should be used responsibly and in accordance with applicable laws, organizational policies, and acceptable-use requirements.
