# BIOS Setup

## Overview

This laboratory activity covered the basic configuration and navigation of the BIOS (Basic Input/Output System) as part of my Cyber Threat Monitoring Level I training.

## Objectives

- Understand the purpose of BIOS
- Navigate basic BIOS settings
- Familiarize myself with system configuration options
- Understand the role of BIOS during system startup

## Skills & Knowledge

- BIOS navigation
- Basic system configuration
- Boot configuration awareness
- Hardware and firmware familiarization

## Cybersecurity Relevance

Understanding system startup and firmware configuration provides foundational knowledge of how a computer initializes its hardware and operating system.

Secure system configuration is an important part of maintaining a secure computing environment.
